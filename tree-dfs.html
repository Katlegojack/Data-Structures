Tree Traversal: DFS

Depth-First Search

DFS explores one branch as deeply as possible before returning to visit another branch. In a binary tree, common DFS orders are preorder, inorder, and postorder.

Problem statement

Traverse the binary tree using DFS and record the order in which the nodes are visited. Compare preorder, inorder, and postorder traversal.
